# 用户指南

国际税收网络实验室是研究国际税收和企业所有权网络的研究工作台。它忠实地运行已发表的方法，准确记录每项结果的产生过程，并支持重放、比较、报告和导出结果。本软件不提供税务或法律意见；一个法域在网络中的位置并非避税、不当行为或违法的证据。

本指南译自英文版。如两者有出入，以英文版为准。

## 1. 启动

**Windows。** 运行安装程序（无需管理员权限）或便携版 `taxnetlab.exe`。系统会打开一个控制台窗口并显示本地地址，界面在浏览器中打开。关闭控制台窗口或点击**退出**即可停止。本软件不通过网络发送任何内容：服务器只监听 `127.0.0.1`。

**从源代码运行。** 需要 Python 3.11 或更高版本：先执行 `pip install -e .`，再执行 `python -m taxnetlab`。

**工作区。** 您的数据集、运行、预期、报告和日志保存在工作区文件夹中：Windows 上为 `Documents\TaxNetLab`，其他系统为 `~/TaxNetLab`。可通过 `--workspace DIR` 或环境变量 `TAXNETLAB_WORKSPACE` 指定其他位置。本软件从不在其安装文件夹内写入内容。

首次启动时会创建一个小型合成世界，使每个页面都有内容可看。合成数据完全是虚构的，并在每张图表和每次导出中如此标注。

## 2. 阅读模式与语言

顶栏可在**通俗说明**（默认）和**技术说明**两种措辞之间切换。每张图表都附有解读说明：在通俗说明模式下展开，在技术说明模式下折叠。界面文字来自语言文件；英文（英国）和简体中文已完整翻译，无需修改代码即可增加其他语言（见 `docs/TRANSLATING.md`）。本指南和方法说明也有简体中文版。

## 3. 数据

一个数据集由若干张表组成（带标题行的 CSV 文件；各列按名称匹配，顺序不限）。必需的表：`sources`、`jurisdictions`、`entities`、`ownership`。可选的表：法域属性（GDP）、税收规则表、营业收入、协定条件和核实日志。**数据**页面显示每张表及其列定义和验证报告。

约定：税率和比例以小数表示（0.25 即 25%）；真实法域使用 ISO 3166-1 alpha-3 代码，虚构法域使用 `FIC_` 前缀；所有权按持有方指向被持有方存储；排除自然人；任何数据都不会在未告知的情况下被修复或推算；合成记录不得涉及真实法域。

数据集采用**内容寻址**：其标识符是各表的哈希值，因此相同内容总是具有相同标识符，任何改动都会产生新的数据集。旧数据集始终可读。

**添加数据。**
* *合成数据生成器*（“数据”页面或 `taxnetlab generate`）。
* *CSV 导入*，每张表一个文件。对于从数据库导出、列名自成一套的文件，可提供**列映射**，例如 `{"ownership": {"holder_id": "Shareholder BvD ID", "source_id": "=ORBIS_2025"}}`（`=数值` 设定常量）。
* *法律编码模板*：示例模板（虚构、完整）展示格式；真实样本模板列出您所选的法域，所有法律字段留空，`verified` 设为 false。依据来源填写法律字段后导入 ZIP 文件。每个模板中的数据字典解释各列及其编码层次（纳税义务、征收、观测）。
* *核实日志*（`rule_verifications`）：谁在何时、对照哪一来源核对了哪一行法律数据，结果如何。

未经核实的法律数据行可以使用，但依赖它们的每项结果都会被标注。

**补全数据集。** 某一方法可能需要数据集所缺少的数据，例如通道与汇点所需的 GDP，或税收路径所需的税收规则。在“数据”页面的**补全本数据集**中，下载已列出本数据集各法域的模板，填写所需的行（每行注明来源）后上传；未填写的行会被忽略。结果是一个记录其补全来源的新数据集，原数据集保持不变。*添加行*保留已存储的行，只替换键相同的行；*替换整张表*会替换您提供的每张表。

## 4. 来自A股公司情报的企业层面数据

**研究工具套件**页面把A股公司情报发布的中国上市公司集团所有权数据导入实验室。转换采用研究工具套件自身的转换器：实验室内置一份固定版本的套件核心，因此此处对数据发布的转换与 ResearchSuite.exe 完全相同。

1. **读取数据发布。** 粘贴数据发布文件夹的路径（其中包含 `manifest.json` 和 `csv` 文件夹）。实验室会显示其内容；不会改动任何东西。
2. **导入。** 选择项目（可在工作区文件夹 `suite_projects` 中新建，或选择已有项目，包括在 ResearchSuite.exe 中创建的项目）和导入选项。自然人一律不导入。疑似解析错误的行（列错位、持股比例不在 0 至 100% 之间、持股合计超过 100%、营业收入未注明口径）会连同原因被搁置，页面会列出这些原因。
3. **审核。** 法域不明确的名称和地点（例如“维尔京群岛”，或未注明所属法域的股东）会被列出。为每一项选择代码，或留空以不纳入，然后点击**保存并重新导入**。选择随项目保存，之后每次导入都会使用，无论是在实验室中还是在 ResearchSuite.exe 中。
4. **导入实验室。** 项目的主体、持股、营业收入和来源成为一个实验室数据集。数据集会记录数据发布、项目、导入设置、尚未处理的审核事项和转换器版本；“概览”页面会显示这些信息。默认不纳入没有任何行引用的法域，以免将每个法域视为一个观测的方法被登记表所主导。

数据发布包含所有权和营业收入，但不含 GDP 或税收规则，因此单独使用时可支持网络页面、矩阵以及使用关联特征（`outward_links`、`inward_links`）的拓扑分析。如需分析通道与汇点，请用 GDP 补全数据集；如需分析税收路径，请用税收规则补全。数据发布中的营业收入为合并口径，会重复计算子公司；导入警告会提示这一点，在营业收入拆分合并口径之前，不应解读通道与汇点的结果。

命令行：`taxnetlab import-ashare 数据发布文件夹 --bring`，以及 `taxnetlab suite list | review | choose | reimport | bring`。ResearchSuite.exe 或快捷方式可用 `taxnetlab --import 路径` 直接在某个数据发布、项目或导出上打开实验室，并可用 `--language zh-Hans` 指定语言。

## 5. 分析页面

* **网络**、**矩阵**：按所有权方向或价值流方向展示的所有权网络，以及法域对法域的矩阵。
* **税收路径**（van 't Riet 和 Lejour）：股息从来源国流向居民国的最低成本路径、择协避税收益和通道排名。调整某一税率或协定，一切都会重新计算。可以适用**协定条件**：持股门槛依据您设定的事实检验；受益所有人、主要目的和利益限制测试在您记录假定之前保持未决。*严格*模式不给予未决的优惠；*附条件*模式保留优惠，并标注依赖这些优惠的路径。
* **通道与汇点**（Garcia-Bernardo 等）：相对于经济规模，企业价值最终流向何处，以及途经哪些法域。
* **拓扑**（持续同调）：各尺度上法域之间的聚类与环，以及该结构依赖于哪些法域。
* **比较**：将各方法的指标并列展示；只有在对原文的所有解读一致时才显示排名。

这些页面上的实时结果是**探索性预览**：它们不会被存储，并带有“探索性”标记。**保存为运行**会将当前状态准确记录为一次运行。

## 6. 运行

一次**运行**是在一个数据集上以一组参数执行一个引擎。其记录不可更改，包含参数和假定、数据标识符、警告、计算轨迹、每个输出的哈希值以及软件环境。在**运行**页面：

* **执行**在后台运行并显示进度；**取消**会停止运行且不存储任何内容。
* **重放**重新执行一次运行并比较每个输出的哈希值。
* **报告（HTML）**是独立完整的报告，适合与论文一同存档。
* **导出数据包**按可复现性等级写出 ZIP 文件：A 级（公开数据：全部内容）、B 级（许可数据：不含数据表，仅在许可允许时包含输出）、C 级（合成数据：全部内容，标注为合成）。其他研究者可通过**复现**或 `taxnetlab reproduce` 复现。
* 若引擎的版本或状态此后发生变化，运行会被标记为**已过时**。

**敏感性扫描**（`sensitivity.sweep`）在参数取值网格上运行某一方法，并报告各法域的排名和分类的稳定程度。

## 7. 方法的状态

每个引擎都带有状态，并显示在每项结果上：*接口*（已登记，无法运行）、*已有规范*、*已实现*（通过针对其规范的全部测试）、*已核实*（作者已对照原始文献核对规范，并在 `docs/verification/records` 中留有完整记录）、*已复现*或*已复现但存在差异*（在冻结的预期下，以真实数据复现了已发表的结果）。低于*已核实*的引擎所产生的结果带有“未核实的方法”标记。

受专利保护的拓扑方法（US 10,417,262 B2）的引擎在知识产权决定作出之前保持接口状态；持续同调是另一种独立的已发表方法。

## 8. 复现已发表的结果

1. 撰写预期条目（草稿见 `docs/expectations`）：已发表的结果、统计量、容差和判定规则。
2. **冻结**该条目（“运行”页面或 `taxnetlab expect freeze FILE --by NAME`）。已冻结的条目不可更改；更正须作为取代原条目的新条目记录。
3. 导入真实数据，以条目要求的参数运行引擎，并对照条目**核对**该运行。系统拒绝核对在条目冻结之前进行的运行。

## 9. 命令行

```text
taxnetlab [serve] [--workspace DIR] [--port N] [--no-browser] [--import PATH] [--language TAG]
taxnetlab import-ashare RELEASE_FOLDER [--project FILE.sqlite] [--companies CODES] [--bring]
taxnetlab suite list | review PROJECT | choose PROJECT NAME=CODE ... | reimport PROJECT | bring PROJECT
taxnetlab generate --seed 42
taxnetlab datasets
taxnetlab import FILE.zip|FOLDER [--name TEXT] [--mapping MAP.json]
taxnetlab template illustrative|real-sample [--jurisdictions NLD,LUX]
taxnetlab run SPEC.json
taxnetlab replay RUN_ID
taxnetlab export RUN_ID [--include-outputs] [--report FILE.html]
taxnetlab reproduce PACKAGE.zip
taxnetlab expect list | freeze FILE --by NAME | check ENTRY_ID --run RUN_ID
taxnetlab selftest
taxnetlab version
```

## 10. 故障排除

* *浏览器没有打开*：请打开控制台窗口中显示的地址。
* *Windows SmartScreen 发出警告*：可执行文件未经代码签名；请将其 SHA-256 与发布中的 `SHA256SUMS.txt` 比对，然后选择“更多信息”“仍要运行”。
* *运行缓慢*：大型税收路径世界会枚举许多近似最优路径；当上限（`max_intermediates`、`max_routes_per_pair`、`route_budget`）起作用时会予以报告。请在“运行”页面执行，它会在后台运行。
* *无法读取数据发布*：请选择包含 `manifest.json` 的数据发布文件夹本身，而不是其中的 `csv` 文件夹。
* *出现问题*：详情写入工作区中的日志文件（`logs/taxnetlab.log`）。

## 11. 隐私

所有内容都保留在您的计算机上。运行时没有遥测，也没有网络访问。导出数据包时，许可数据的写入范围绝不超出您确认许可所允许的范围。
