# API reference

Generated by `scripts/make_api_docs.py`; do not edit by hand.

## HTTP interface

The interface server listens on 127.0.0.1 only. POST requests need the header `X-TaxNetLab-Token` (the session token embedded in the page) and `Content-Type: application/json`. Errors are JSON `{"error": {"code", "message"}}` with status 400, 403, 404, 413, 415, 421 or 422.
