## HTTP interface

The interface server listens on 127.0.0.1 only. POST requests need the header `X-TaxNetLab-Token` (the session token embedded in the page) and `Content-Type: application/json`. Errors are JSON `{"error": {"code", "message"}}` with status 400, 403, 404, 413, 415, 421 or 422.

## Python service layer (`taxnetlab.api.Api`)

The interface, the command line and notebooks use the same class: `Api(Workspace(path))`.

### `about() -> 'dict[str, Any]'`

### `add_reference(data: 'bytes', retrieved: 'str', filename: 'str' = '') -> 'dict[str, Any]'`

### `appendix(run_id: 'str', fmt: 'str' = 'md') -> 'bytes'`

The run as a methods appendix: Markdown, HTML or Word (.docx).

### `check_replication(entry_id: 'str', run_id: 'str') -> 'dict[str, Any]'`

Compare a stored run with a frozen entry; the report is stored once and never rewritten.

### `complete_from_reference(dataset_id: 'str', reference_id: 'str', period: 'str', name: 'str | None' = None) -> 'dict[str, Any]'`

A new dataset with GDP for the dataset's real jurisdictions from a reference set, for one period.

Values are copied exactly; jurisdictions without a value for the period are reported, never filled.
Stored GDP rows for the same jurisdiction and period are replaced (rows with the same key).

### `completion_template(dataset_id: 'str') -> 'bytes'`

A real-sample coding template (GDP and tax rules) listing the dataset's real jurisdictions.

### `dataset(dataset_id: 'str') -> 'dict[str, Any]'`

### `datasets() -> 'list[dict[str, Any]]'`

### `derive_dataset(base_id: 'str', name: 'str', texts: 'dict[str, str]', mode: 'str' = 'merge', extra_meta: 'dict[str, Any] | None' = None) -> 'dict[str, Any]'`

Complete a dataset: a new dataset with some tables added or replaced (the original is unchanged).

``merge``: rows supplied replace stored rows with the same primary key and the rest are added;
``replace``: each supplied table replaces the stored table entirely. In ``merge`` mode column names are
matched without regard to case, tables supplied with no rows are ignored, and so are unfilled template
rows (rows with nothing but their key and the template's ``verified = false``), so that a completion
template can be uploaded without deleting the rows left blank. The new dataset records what it was
derived from.
